# Cryptography Missions

A standalone, student-facing teaching demo for blockchain cryptography.

## Contents

1. Shared-secret symmetric encryption
2. Animated public-lock/private-key safe analogy
3. Fruit-shake hashing with an explicit banana change from 47 g to 48 g
4. Digital signatures and blockchain transaction verification

Each lesson is tutor-controlled and self-paced. Click **Next** or **Back** to reveal one visual step at a time. The explanation and key concept are displayed beside every animation.

## Deployment

This package is a static site. It requires no build system, backend, wallet or blockchain connection.

### GitHub Pages

1. Copy the folder contents into a repository folder, for example:
   `blockchain/cryptography-missions/`
2. Commit and push the files.
3. Ensure GitHub Pages is enabled for the repository.
4. Link to the resulting `index.html` page from the Blockchain Teaching Resources section of the website.

## Files

- `index.html` — page structure
- `styles.css` — layout, icons and animations
- `app.js` — lesson content, navigation and scene rendering

## Browser support

Current Chrome, Edge, Firefox and Safari.
