# Blockchain Network Explorer

A static teaching demo for Week 4 blockchain topics. It follows the same compact, student-facing lesson style used in the earlier blockchain teaching resources.

## Included lessons

1. **Where Control Lives**  
   Explains centralised, distributed and decentralised systems.

2. **From Intermediary to Blockchain**  
   Explains disintermediation, when blockchain may be useful, and the storage / communication / computation layers.

3. **Smart Contract Escrow**  
   Explains smart contracts, DApp structure and a delivery escrow example.
